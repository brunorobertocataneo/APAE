# APAE Videira — Impacto+

Protótipo de interface para apresentar uma campanha de doações para a APAE Videira.

## O que você encontra

- Seleção de valores sugeridos ou de um valor personalizado, com mensagem de impacto.
- Seções demonstrativas de impacto e acompanhamento de doações.
- O código da página demonstra a interface. A seleção do valor não processa um pagamento.

## Executar localmente

Baixe ou clone o repositório e sirva a pasta raiz com um servidor estático. Com Python 3 instalado, execute `python -m http.server 8000` e acesse [localhost:8000](http://localhost:8000/).
